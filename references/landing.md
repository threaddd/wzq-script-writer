# 三类用户衔接 + 行动引导（CTA）句式库

> 对应 `instruction.md` 第二章 b/c 节。产品衔接必须从新闻逻辑自然生长，不能突然插入。

---

## 三类用户衔接模板

先判断目标用户属于哪一类，再对应引出产品。三条连续脚本不能使用同一类。

### i. 不了解热点资讯型

**适用**：看到热点但看不懂背后逻辑，想获取专业资讯和行业解读入口。

**句式库**：
- 「腾讯微证券不仅有专业解读，还提供了简单的开户流程，在微信上就能开户试试了。」
- 「很多人刷到这类消息，想了解这件事到底意味着什么，但不知道该关注什么。腾讯微证券上有这类行情资讯和专业解读，在微信上就能看。」
- 「对普通人来说，你不需要跟着做什么决定，但这类信号释放出来的时候，了解一下没坏处。腾讯微证券上有这类资讯和行情解读，在微信上就能看。」

**核心扣点**：开户 = 看懂背景 + 查到逻辑

---

### ii. 消息过载型

**适用**：热点变化快，靠自己盯着刷容易漏掉，需要能帮着盯的工具。

**句式库**：
- 「这类信息更新得快，靠自己盯着刷容易漏。腾讯微证券行情有动静微信直接通知你，不用自己一直盯着刷，微信上就能开户试试。」
- 「这么多信息靠自己盯着看很容易漏，腾讯微证券能帮你跟进，行情有变化微信直接通知你，微信上就能开户试试。」
- 「市场信息变化快，靠自己盯容易漏，腾讯微证券能帮你跟进，行情有变化微信直接通知你。」

**核心扣点**：开户 = 不掉队 + 跟得上

---

### iii. 跃跃欲试型

**适用**：看到了行情变化，但一直觉得开户流程麻烦，总没动手。

**句式库**：
- 「其实开户没那么难，用腾讯微证券，微信上就能开户了，花不了几分钟，开好之后行情资讯直接在微信里看。」
- 「很多人看到这种消息，其实早就想开个账户关注了，只是一直觉得流程麻烦没动手。其实开户没那么难，用腾讯微证券，微信上就能开户了，花不了几分钟。」
- 「很多人看到这些动作，其实早就想自己也开个户了解一下了，只是觉得流程复杂没动手。用腾讯微证券，微信上就能开户，花不了几分钟。」

**核心扣点**：开户 = 门槛比想象低 + 行动即可开始

## 行动引导（CTA）句式库

直接选用以下 CTA，每次输出前先确认上一条用的是哪句，本次必须选不同的：

1. 感兴趣的话，点下方链接开个账户试试吧。
2. 点击下方链接试试吧。
3. 感兴趣的话，点击下方链接开户试试。
4. 有兴趣的话，点下方链接，开户试试吧。

**CTA 类型归类**（用于快讯与主脚本轮换检查）：
- 开户引导类：「开个账户」「开一个」「开户试试」
- 了解资讯类：「来微证券看看」「去腾讯微证券了解下」
- 点链接类：「点下方链接了解」

---

## 写作自查（必过）

每写完一条衔接 + CTA，问自己 3 个问题：

1. **前面有没有铺垫？** 观众已经跟着新闻产生了疑问或需求，产品作为回应自然出现；如果没有，就是硬性插入。
2. **语气是否催促 / 说教 / 拉踩？** 如果是，改自然分享。
3. **CTA 是否和上一条重复？** 连续两条不能用同一句或同一类型。

---

## 禁止项

| 禁止表达 | 原因 |
|---|---|
| 突然插入「微信上可以炒股了」 | 无逻辑承接（衔接规则） |
| 我建议你去开户 / 你应该开个户 | 说教语气，触发防御 |
| 赶紧点击下方链接体验吧 | 过强催促 |
| 不用再只当旁观者 | 拉踩 + 暗示损失（红线9） |
| 不开户就会 XX | 暗示损失（红线2） |
| 出现具体板块名称（电力/AI/机器人） | 过于具体，改用「行情信息」「相关动态」 |
