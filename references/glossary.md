# 专业词通俗化对照表

> 目标用户是投资新手，所有表达必须用日常话说出来，让从没炒过股的人也能秒懂。

## 核心原则

1. **能用大白话说就别用术语**
2. **必须用术语时，后面接一句解释**
3. **比喻要贴近日常生活，不要再用一个抽象比喻解释抽象概念**

---

## 完整对照表

| 专业词 | 通俗替换 |
|---|---|
| 产业链公司 | 做这行的上市公司 |
| 询价、申购环节 | 申购是怎么一回事 |
| 流动性 | 钱好不好借 |
| 估值 | 公司值多少钱 |
| 市场情绪 | 投资者怎么看 |
| 超级周期 | 行业进入快速发展阶段 |
| 资金面 | 钱往哪流 |
| 首日破发 | 上市第一天就跌破发行价 |
| 资本开支 | 公司投钱建厂、买设备 |
| IDM 模式 | 公司自己设计、自己生产 |
| 出海 | 卖到国外 |
| 同比 / 环比 | 跟去年同一时间比 / 跟上个月比 |
| 资金净买入 | 买进的钱比卖出的多 |
| 逆势加仓 | 跌的时候反而买进 |
| 板块轮动 | 资金从一类股票转到另一类 |
| 两融余额 | 借钱买股票的总规模 |
| 杠杆资金 | 借钱进场的资金 |
| 北向资金 | 海外投资者买 A 股的钱 |
| 量化交易 | 用电脑程序自动买卖 |
| 龙头股 | 这个行业最有代表性的几家公司 |
| 主力资金 | 大体量的资金 |
| 拉升 / 砸盘 | 价格快速涨 / 快速跌 |
| 业绩对赌 | 公司承诺达到一定业绩 |
| 商誉减值 | 公司之前的并购"亏了" |
| 解禁 | 之前不能卖的股票，现在可以卖了 |
| 分红 | 公司把赚到的钱分给股东 |
| 派息 | 公司发放红利 |
| 一级市场 / 二级市场 | 公司上市前的融资 / 上市后的买卖 |
| 增发 | 公司再发行新股票筹钱 |
| 回购 | 公司花钱买自己的股票 |

## 常见诱导词中性化对照（合规要求）

| 诱导表达 | 中性替换 |
|---|---|
| 暴涨、爆发、起飞 | 上涨 / 持续上行 / 涨幅显著 |
| 跌停潮、闪崩 | 整体回调 / 普跌 |
| 风口、机会、红利 | 热点方向 / 受到关注 |
| 抓住机会、把握风口 | 关注动态 / 跟上节奏 |
| 必涨、肯定涨、稳赚 | （删除，不可用） |
| 值得布局、值得抄底 | 受到资金关注 |
| 千万别错过、抓紧时间 | 感兴趣可以了解 |
| 股价往往会跟着动 | 相关板块自然受到关注 |
| 规律性机会 | （删除，不可用） |
